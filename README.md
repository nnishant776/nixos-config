# NixOS / nix-darwin Configuration Flake

A multi-platform configuration flake that manages NixOS and macOS machines from one
repository. Machines are declared under `hosts/`, behaviour is driven by the
`myconf.*` option tree, and [profiles](#profiles) provide sensible role-based
presets that every host can selectively override.

## Repository Layout

```
├── flake.nix                        # entry point: discovers hosts/, builds configurations
├── lib/
│   └── mkHost.nix                   # host factory: routes Linux vs Darwin, wires modules
├── hosts/<machine-name>/            # ONE directory per machine (auto-discovered)
│   ├── meta.nix                     # system = "x86_64-linux" | "aarch64-darwin" | ...
│   ├── hardware-configuration.nix   # Linux only, generated by nixos-generate-config
│   └── default.nix                  # this machine's myconf.* settings
└── modules/
    ├── core/                        # shared baseline loaded on every host
    │   ├── base-packages.nix        # canonical CLI tool list (single source)
    │   ├── base.nix                 # installs the baseline (+ bash) system-wide
    │   └── development/             # myconf.development packages (Linux + macOS)
    │       ├── default.nix · sdk.nix · editors.nix · tools.nix
    ├── myconf/                      # the configuration interface
    │   ├── options.nix              # declares the full myconf.* option tree
    │   ├── profile.nix              # profile presets (applied via lib.mkDefault)
    │   └── implications.nix         # e.g. desktop.enable ⇒ multimedia/graphics/...
    ├── home/                        # Home-Manager layer
    │   ├── home-manager.nix         # registers users (adminUser + extraUsers) with HM
    │   ├── default.nix              # per-user baseline (stateVersion, ...)
    │   └── git.nix                  # git configuration
    └── system/
        ├── linux/                   # NixOS implementation of myconf.*
        │   ├── base.nix             # NixOS-only infra: PATH vars, nix-index, nix-ld
        │   ├── host.nix             # hostname, users, group grants from myconf.host
        │   ├── locale.nix           # i18n from myconf.host.locale
        │   ├── development/         # myconf.development nix-ld export (Linux-only)
        │   ├── services/            # myconf.systemServices.*, one file per service
        │   └── desktop/             # myconf.desktop.*  → apps, fonts, shells
        └── darwin/                  # macOS implementation (settings)
```

## How Configuration Works

Adding a machine requires no changes to the flake itself:

1. **Create `hosts/<machine-name>/`** containing:
   - `meta.nix` — declares the platform (`system = "x86_64-linux";`).
     `flake.nix` auto-discovers every directory in `hosts/`, elaborates each
     `meta.nix`, and routes it to `nixosConfigurations` or `darwinConfigurations`.
   - `hardware-configuration.nix` — Linux hosts only (from the installer).
   - `default.nix` — the machine's `myconf.*` configuration.
2. **Evaluate/build**:
   ```bash
   nixos-rebuild   switch --flake .#<machine-name>   # Linux
   darwin-rebuild  switch --flake .#<machine-name>   # macOS
   ```

`lib/mkHost.nix` then assembles the module stack:

| Layer | Module | Role |
|---|---|---|
| 1 | `hosts/<name>/default.nix` | your settings (highest effective priority) |
| 2 | `modules/core` | cross-platform baseline: CLI tools, dev tooling |
| 3 | `modules/myconf` | option declarations + profile presets + implications |
| 4 | `{ nixpkgs.hostPlatform = <system>; }` | platform plumbing |
| 5 | `modules/home/home-manager.nix` | Home-Manager wiring for each enabled user |
| 6 | `modules/system/linux` *or* `modules/system/darwin` | platform implementation of `myconf.*` |

### Users & Home-Manager

`myconf.host.adminUser` (plus optional `myconf.host.extraUsers`) drives both the OS
accounts (`host.nix`) and Home-Manager users (`home-manager.nix`). Users with
`enableHomeManager = true` get the shared config in `modules/home/` plus whatever
they declare in their own `extraHomeConfig`. Group membership is granted
automatically: `video`/`input` (desktop), `docker`/`podman` (containers),
`libvirtd`/`kvm` (VMs), `networkmanager` (networking).

## Option Reference (`myconf.*`)

### `myconf.host`

| Option | Type | Default | Description |
|---|---|---|---|
| `host.name` | str | `"localhost"` | Hostname |
| `host.timezone` | str | `"Asia/Kolkata"` | Timezone |
| `host.locale` | str | `"en_IN"` | Locale (also sets all LC_* vars) |
| `host.adminUser` | user submodule | `{}` | Primary user (see below) |
| `host.extraUsers` | list of user submodule | `[]` | Additional accounts |

User submodule fields:

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | str | `"admin"` | Username |
| `fullName` | str | `"Administrator"` | Full name (used for git) |
| `email` | str | `""` | Git email (falls back to `<name>@localhost`) |
| `groups` | listOf str | `[ "wheel" ]` | Extra groups (platform groups are auto-added) |
| `initialHashedPassword` | str | *(hash)* | Initial password — change after install |
| `enableHomeManager` | bool | `true` | Register this user with Home-Manager |
| `extraHomeConfig` | deferredModule | `{}` | Extra per-user HM configuration |

### `myconf.profile`

One of `minimal` · `server` · `workstation` · `developer` · `gaming` · `embedded`
— see [Profiles](#profiles).

### `myconf.desktop`

| Option | Type | Default | Description |
|---|---|---|---|
| `desktop.enable` | toggle | `false` | GUI stack, display managers |
| `desktop.environment` | nullOr enum: `gnome`/`hyprland`/`sway`/`all` | `null` | Which DE(s) to activate |
| `desktop.environments.hyprland.shell` | enum: `none`/`caelestia`/`noctalia` | `"none"` | Hyprland shell |
| `desktop.packages` | listOf package | `[]` | Replaces default desktop app set |
| `desktop.extraPackages` | listOf package | `[]` | Appended to desktop apps |

Enabling the desktop implies (via `implications.nix`, weakly): multimedia,
graphics, powerManagement, flatpak.

### `myconf.systemServices`

| Option | Type | Default | Description |
|---|---|---|---|
| `systemServices.bootloader.program` | nullOr enum: `systemd-boot`/`grub`/`uboot` | `"systemd-boot"` | Bootloader |
| `systemServices.bootloader.allowEFIVariableEdit` | toggle | `false` | Allow writing EFI vars |
| `systemServices.networking.enable` | toggle | `false` | NetworkManager |
| `systemServices.networking.wifi.enable` | toggle | `false` | WiFi backend |
| `systemServices.multimedia.enable` | toggle | `false` | Audio/video stack (PipeWire-ready pkgs) |
| `systemServices.multimedia.extraPackages` | listOf package | `[]` | Extra media packages |
| `systemServices.multimedia.nix-ldLibraries` | listOf package | `[]` | Extra nix-ld libs for media |
| `systemServices.graphics.enable` | toggle | `false` | HW acceleration |
| `systemServices.graphics.vendor` | enum: `intel`/`amd`/`nvidia` | `"intel"` | Driver selection |
| `systemServices.graphics.extraPackages` | listOf package | `[]` | Extra GPU packages |
| `systemServices.graphics.nix-ldLibraries` | listOf package | `[]` | Extra nix-ld libs for GPU |
| `systemServices.powerManagement.enable` | toggle | `false` | tuned/upower daemons |
| `systemServices.containerisation.enable` | toggle | `false` | Docker (rootless) + Podman |
| `systemServices.containerisation.extraPackages` | listOf package | `[]` | Extra container tools |
| `systemServices.virtualisation.enable` | toggle | `false` | KVM/QEMU/libvirt/virt-manager |
| `systemServices.virtualisation.extraPackages` | listOf package | `[]` | Extra VM tools |
| `systemServices.virtualisation.nix-ldLibraries` | listOf package | `[]` | Extra nix-ld libs for VMs |
| `systemServices.homebrew.enable` | toggle (Darwin) | `false` | Homebrew integration |
| `systemServices.homebrew.brews` / `.casks` | listOf str | `[]` | Formulae / casks |
| `systemServices.homebrew.masApps` | attrsOf int | `{}` | Mac App Store apps (Name = id) |
| `systemServices.homebrew.onActivation.autoUpdate/.upgrade` | bool | `false` | Auto-update on activation |
| `systemServices.homebrew.onActivation.cleanup` | enum `none`/`uninstall`/`zap` | `"none"` | Cleanup mode |
| `systemServices.flatpak.enable` | toggle | `false` | Flatpak support |

### `myconf.development`

Top level:

| Option | Type | Default | Description |
|---|---|---|---|
| `development.enable` | toggle | `false` | Master switch for the dev stack |
| `development.extraPackages` | listOf package | `[]` | Always-installed dev extras (plus `uv`) |

Each SDK (`sdk.base`, `sdk.cpp`, `sdk.go`, `sdk.rust`, `sdk.python`, `sdk.java`,
`sdk.nix`, `sdk.lua`) and each CLI tool (`tools.gemini`, `tools.opencode`,
`tools.rtk`) shares this shape:

| Field | Type | Default | Description |
|---|---|---|---|
| `enable` | toggle | `false` | Install this group |
| `packages` | listOf package | `[]` | **Replaces** the curated default package set |
| `extraPackages` | listOf package | `[]` | **Appends** to the default set |
| `nix-ldLibraries` | listOf package | `[]` | Runtime libs exported to nix-ld |

Editors follow the SDK shape plus config-source fields:

| Editor | Extra fields |
|---|---|
| `editors.neovim` / `editors.emacs` | `configPath` (str, local path), `configRepo` (str, remote) |
| `editors.vscode` | standard fields only |

## Profiles

Profiles are **one-line role presets**. Setting `myconf.profile = "<role>"`
enables a coherent bundle of services and tools — every value is applied with
`lib.mkDefault`, i.e. *weakly*, so any host setting wins automatically.

| Profile | Enables |
|---|---|
| `minimal` | networking |
| `server` | networking · containerisation · virtualisation · development + `sdk.base` |
| `workstation` | networking + wifi · multimedia · graphics · desktop · powerManagement · flatpak |
| `developer` | *workstation set* + containerisation + virtualisation + development (`sdk.base…lua`, neovim, emacs) |
| `gaming` | *workstation set* (multimedia/graphics/desktop included) |
| `embedded` | networking + development + `sdk.base` + `sdk.cpp` |

Notes:
- `developer` enables **all SDKs and neovim/emacs**, but not `editors.vscode`
  nor any `tools.*` — enable those per host if wanted.
- `gaming` currently mirrors the workstation service set; add game launchers via
  `desktop.extraPackages`.
- Enabling `desktop` anywhere also pulls in multimedia/graphics/power/flatpak
  (weak implication).

Usage — just set it in the host config:

```nix
# hosts/my-server/default.nix
{
  myconf.profile = "server";
}
```

## Overriding Profile Defaults Per Host

Because presets use `lib.mkDefault` (priority 1000) and plain host assignments
use priority 100, **any value you write in a host config silently wins** — no
special syntax required. Toggle something off, swap an enum, extend lists:

```nix
# hosts/my-laptop/default.nix
{ config, pkgs, lib, ... }: {
  myconf = {
    profile = "developer";                    # start from the preset...

    host.name = "MY-LAPTOP";

    systemServices = {
      containerisation.enable = false;        # ...but no Docker/Podman here
      graphics.vendor = "nvidia";             # preset assumed Intel; pick NVIDIA
    };

    desktop = {
      environment = "hyprland";               # not "all"
      environments.hyprland.shell = "caelestia";
      extraPackages = with pkgs; [ discord spotify ];
    };

    development = {
      sdk = {
        go.enable = false;                    # don't need Go on this box
        python.extraPackages = [ pkgs.black ];# append to Python's default set
      };
      tools.opencode.enable = true;           # profile leaves tools off by default
    };

    host.adminUser.extraHomeConfig = {        # per-user Home-Manager additions
      programs.alacritty.enable = true;
    };
  };
}
```

Rules of thumb:

| You want | Use |
|---|---|
| Override a profile `enable`/enum/string | plain assignment (always wins) |
| Append to a list option | `extraPackages` (or plain list assignment — lists concatenate) |
| Replace a curated default list | `packages` |
| Beat another module's `mkForce`/explicit value | `lib.mkForce` (priority 50) |

Inspecting final values without switching:

```bash
nix eval .#nixosConfigurations.my-laptop.config.myconf.systemServices.graphics.vendor
```
